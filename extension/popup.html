Layout

Browser layout

Vertical tabs are a Firefox setting: Settings → General → Browser layout → Vertical tabs. Argon styles them automatically.

Ctrl+Alt+C toggles frameless mode

One-time setup needed

Firefox only allows hiding its toolbars through a small CSS file. Run this in PowerShell, then fully restart Firefox:

Mac, Linux, or manual setup
  1. In about:config, set toolkit.legacyUserProfileCustomizations.stylesheets to true.
  2. Open about:support and click Open Folder next to Profile Folder. Make a chrome folder there if it's missing.
  3. Save the CSS below as compact.css in that folder.
  4. Add @import "compact.css"; as the first line of both userChrome.css and userContent.css (create them if needed).
  5. Fully restart Firefox.
Not working with your theme?

Frameless mode works with any theme, unless the theme itself sets these with !important:

  • max-height, min-height or overflow on #TabsToolbar, #nav-bar or #PersonalToolbar
  • position or transform on #navigator-toolbox (themes with their own auto-hiding or floating toolbars)
  • position on #sidebar-container (vertical tabs)

Also make sure @import "compact.css"; is the first line of userChrome.css. The layout picker only appears with the Argon theme.
